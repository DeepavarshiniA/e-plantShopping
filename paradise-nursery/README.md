# Paradise Nursery Shopping Application

## About the Project
Paradise Nursery is a plant shopping application built using React. It allows users to browse plants and manage their shopping cart.

## Features
- Home page with a welcome message and About Us section.
- Plant catalog organized into three categories.
- Add plants to the shopping cart.
- Increase and decrease plant quantities.
- Remove plants from the cart.
- Automatic calculation of item prices and total cost.
- Navigation between Home, Plants, and Cart pages.

## Technologies Used
- React
- JavaScript
- Vite
- Redux Toolkit
- React Redux
- React Router
- HTML and CSS

## How to Run
1. Open the project folder in a terminal.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.

## Project Files
- `src/App.jsx` — Main application and routing.
- `src/App.css` — Application styles.
- `src/components/AboutUs.jsx` — About Us section.
- `src/components/ProductList.jsx` — Plant catalog.
- `src/components/CartItem.jsx` — Shopping cart functionality.
- `src/redux/CartSlice.jsx` — Redux cart management.
